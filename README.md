# 🎬 哔哩哔哩（bilibili.com）调整

> 一个主要用于自用的 B 站体验增强用户脚本，V3 重构版。
>
> 因脚本托管网站（如 GreasyFork）不允许上传混淆压缩后的代码，该版本不再通过脚本托管网站发布，仅托管在个人服务器，支持自动检查更新并弹窗提醒。

**当前版本：`v3.23.4`**（最后更新 `09.03 2026`，更新日志见文末）

---

## ✨ 功能概览

- **三端全适配** — 首页 / 播放页（普通视频 + 番剧）/ 动态页均有对应增强
- **浏览器全适配** — 适配 Chrome、Firefox 等主流浏览器（Tampermonkey / Violentmonkey / ScriptCat）
- **页面内设置面板** — 无需依赖脚本管理器菜单，弹窗内直接修改设置，更改即生效
- **AI 广告识别与跳过** — 结合 AI 字幕识别广告片段自动跳过，结果全网共享缓存
- **评论区增强** — IP 属地展示、标签移除、简介嵌入、内容链接化、时间锚点跳转
- **播放体验优化** — 自动定位播放器、模式记忆、画质音质选择、网页全屏解锁、进度记忆、画面旋转
- **数据安全** — 播放进度、历史记录等个人数据仅存本地；广告识别缓存上传服务器用于跨用户共享，附带的上传者 uid 仅用于归属区分、防止误修改

> **注意**：利用空闲时间开发维护，虽长期使用未发现重大问题，但仍无法保证完全没有 Bug。若使用中遇到问题请反馈，会尽快处理。

## 🛠 功能列表

### 📄 通用

- **页内设置面板** — 播放页与动态页侧边栏均有「设置」按钮，弹窗内按分类（基础设置 / AI 服务 / 更新配置 / 日志配置）调整，勾选即时生效、刷新页面即持久
- **跨标签页实时同步** — 任一标签页修改设置，其他已打开的页面立即应用可即时生效的行为（如开关自动跳过广告、网页全屏解锁等）
- **配置导入 / 导出** — 设置弹窗底部一键备份与恢复全部配置
- **分级日志** — 信息 / 错误 / 警告 / 调试四级可独立开关，便于排查问题
- **自动更新** — 支持自动检查（频率可设）、弹窗提醒、自动更新与跳过更新；点击设置弹窗右上角版本号可随时手动检查

### 🏠 首页

- **推荐视频历史记录** — 自动记录每次「换一换」前首页前 11 个非广告推荐位（含标题 / UP 主 / 封面 / 分类 / 所在批次），防误点刷新错过想看的视频；历史弹窗支持：
  - 按 UP 主名 / 标题实时搜索
  - 按视频分类筛选
  - 按批次倒序展示 + 无限滚动加载
  - 一键清空全部记录
- **付费视频标记** — 自动检测推荐流中的付费视频，在卡片标题前添加「付费视频」角标，避免误点

### 📰 动态页

- **默认显示「投稿视频」** — 进入动态页自动切换至投稿视频 tab（目标链接可在动态页设置中修改）
- **评论区增强** — 与播放页评论设置联动：显示评论 IP 属地、移除「UP主觉得很赞」等标签

### ▶️ 播放页

#### 定位与模式
1. **自动定位至播放器** — 进入页面自动滚动至播放器；支持分别开关普通视频 / 番剧、自定义顶部偏移量、点击播放器任意位置重新定位；切换分 P / 选集后自动回位
2. **播放器默认模式** — 自动切换为宽屏 / 网页全屏 / 关闭；上下集切换时保持当前屏幕模式（宽屏 / 网页全屏 / 真全屏均可分别记忆）
3. **网页全屏解锁** — 网页全屏模式下播放器占满页面顶部且页面可正常滚动查看下方评论等内容；播放器工具条自动添加「跳至评论区」「UP主空间」按钮；从真全屏退出后自动恢复网页全屏状态

#### 画质与音质
4. **自动选择最高画质** — 可选包含 4K / 8K（大会员），其余场景自动选 4K / 8K 外最高画质
5. **自动开启「Hi-Res 无损音质」**（大会员）
6. **自动取消静音** — 进入页面若处于静音状态则自动取消

#### 评论与简介
7. **视频简介优化 + 插入评论区** — 将简介中的链接（URL / BV 号 / cv 号 / @用户名 / 时间点）链接化替换；简介过长被折叠时，自动将完整简介以「UP主」样式插入评论区首条，无需点击展开
8. **时间锚点跳转** — 点击简介或评论中的时间链接，自动定位播放器并跳转到对应时刻播放
9. **评论区增强** — 显示 IP 属地、移除「UP主觉得很赞」等标签、评论正文链接化（含去重防嵌套）

#### 字幕与进度
10. **自动开启 AI 中文字幕** — 每个视频自动开启；播放器控制栏提供一键快捷开关（与设置联动）；可开启「切换选集保持字幕开关状态」（手动关闭后切换选集不再自动打开）
11. **播放进度记忆** — 独立于 B 站官方进度记忆的兜底方案：切换选集 / 关闭页面记住位置并自动恢复；已播完自动清除记录；手动拖动过进度条的视频不再自动恢复，避免与用户意图冲突

#### 广告识别（需配置 AI）
12. **自动跳过广告** — 通过 AI 分析视频 AI 中文字幕识别广告片段（硬广、软广、口播植入、片尾推广等）并自动跳过；需要视频带有 AI 字幕，无字幕自动关闭
13. **跳过片段管理** — 侧边栏「管理」按钮打开片段管理弹窗：
    - 优先展示本地 / 远程缓存的跳过片段，可按需删除
    - 「重新识别」通过 AI 重新分析当前视频
    - 「手动添加」批量填写片头片尾等固定片段（自动检测重叠冲突、合并相邻片段）
    - 「更新缓存」一键同步本地与服务器
14. **全网共享识别结果** — 识别结果上传至服务器共享缓存，同一视频其他人无需重复调用 AI；记录含上传者 uid（仅用于区分上传者防止误修改）与锁定字段，防止正确数据被误改

#### 侧边工具与交互
15. **侧边悬浮工具栏** — 定位 / 设置 / UP主空间 / 跳过片段管理 等按钮常驻侧边，随时可用
16. **UP主空间弹窗模式** — 「UP主空间」可选择新标签页或页内弹窗打开；弹窗内隐藏站点头部、不打断当前浏览，关闭后缓存复用不再重新加载
17. **视频画面旋转** — 播放器右键菜单新增「复原 / 顺时针90° / 逆时针90°」，全屏切换自动保持旋转状态
18. **选集菜单解锁** — 多 P / 合集 / 番剧页点击任意集数后自动定位回播放器，无需手动滚动寻找播放位置

#### AI 服务配置要点
- **提供商**：内置 硅基流动 / DeepSeek 官方 / Kimi（月之暗面）/ 智谱 AI / OpenAI 预设，模型列表随提供商动态加载
- **自定义模型**：可关闭预设，直接填写任意 OpenAI 兼容的 API 地址 / Key / 模型 ID
- **费用**：识别精度取决于所选模型，识别消耗 token 会按各平台标准计费，请先在对应平台查看价格
- **隐私**：API Key 仅保存在本地，切勿在公共设备上保存；请妥善保管
